# The Moon

A quiet lunar observatory experience.

## Views

- Telescope eyepiece view
- Dedicated lunar observatory room

Tap the scene to move between the two views.

## Location and weather

The location picker follows the shared catalog used by `bennessism/window`. Current cached weather from that project controls clear, cloudy, rainy, and storm atmosphere.

## Moon data

The first visual build includes a local lunar-cycle calculation so the phase changes automatically without requiring a live API call on every visit.

The intended production data source is NASA Goddard SVS / LRO yearly Moon Phase and Libration data, cached into this repository rather than queried once per visitor.

NASA source:
- Moon Phase and Libration, 2026 — NASA Scientific Visualization Studio
- Dial-A-Moon / LRO imagery and astronomical data
